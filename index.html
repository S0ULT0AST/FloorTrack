Google Sheets Sync
Connect to your Google Sheet via Apps Script. All changes in FloorTrack push to the sheet in real time.
Connection

Sync
The sheet is the master copy. Pull imports all rows into FloorTrack (skipping serials already present).
All changes you make in FloorTrack are pushed to the sheet automatically.
Setup Instructions
  1. Open your Google Sheet
  2. Click Extensions → Apps Script
  3. Delete everything and paste the contents of FloorTrack_Sheets.gs
  4. Update SHEET_NAME if your tab isn't named "Sheet1"
  5. Click Deploy → New deployment → Web app
  6. Set Execute as: Me · Who has access: Anyone
  7. Copy the Web app URL and paste it above, then click Connect
  8. Click Pull from Sheet to import your inventory
